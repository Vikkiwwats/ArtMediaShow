# Фотографии мероприятия AMS

Источник: четыре фотографии заказчика, присланные 23 ноября 2026 года. Название, год и город мероприятия отдельно не подтверждены, поэтому на сайте использовано нейтральное название «Большая концертная площадка».

Сохранённые файлы: fire-wide.webp, fire-close.webp, blue-crowd.webp, day-stage.webp и их версии -thumb.webp в этой папке.

Три ночных кадра обработаны встроенным ImageGen для мягкой очистки сжатия и увеличения. Это ретушь присланных кадров, не вымышленная сценическая постановка. При увеличении мелкие детали могут отличаться от оригинала; изображения не предназначены для документальной идентификации деталей. Дневной кадр опубликован из оригинального файла без генеративной ретуши: при пробной обработке изменялись мелкие детали лиц. Для публикации выполнена только конвертация в WebP.

Полные промпты и входные имена файлов: IMAGE-PROMPTS.json.
